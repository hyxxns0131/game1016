게임 방법

좀비로 가득 찬 교도소. 한 명은 죄수가 되어 탈출하고, 한 명은 교도관이 되어 막는다. 둘 다 좀비에게 잡히면 즉시 패배.

죄수

목표 맵에 흩어진 열쇠 조각 3개를 모아 운동장 동쪽 정문으로 탈출

  • C 사물함에 숨기 — 최대 10초, 교도관·좀비에게 안 보임
  • 교도관에게 잡히면 감방으로 끌려가고 열쇠 1개를 떨어뜨림
  • 지도에 남은 열쇠 위치가 노란 점으로 표시됨

교도관

목표 10분 동안 죄수의 탈출을 막기

  • C 문 잠그기 — 동시에 3개까지, 25초 뒤 자동 해제
  • 넓은 손전등 시야 (단, 멀리서도 불빛이 보임)
  • 죄수와 부딪히면 체포 → 죄수를 감방으로 돌려보냄

조작

←↑↓→ 이동
마우스 클릭 그 지점으로 이동 (누른 채 끌면 따라감)
X 달리기 — 빠르지만 스태미나 소모, 소음 발생
Space 점프 — 탁자·침대 넘기, 공중에선 잡히지 않음
Z 앉기 — 느리지만 조용함, 좀비·교도관에게 잘 안 보임
C 행동 — 숨기 / 문 잠그기
M 지도 열기/닫기 (오른쪽 위)

좀비

하수구·환풍구에서 기어 나온다. 가까운 사람을 보면 쫓아오고, 달리기·문 여닫기·착지 소리에 몰려든다. 시간이 지날수록 강해진다.

상 6분~
빠르고, 문을 부수는 거대 좀비

승리 조건

  • 죄수가 정문으로 탈출 → 죄수 승리
  • 10분이 지남 → 교도관 승리
  • 좀비에게 잡힘 / 연결이 끊김 → 상대 승리

플레이 방법

  • 혼자 하기 — 내가 죄수, AI 교도관과 대결
